# Ambient RNA removal benchmarking reproducibility 

This repository contains scripts for reproducing the analyses presented in the ambient RNA removal benchmakr paper, as well as for downloading data.

## Citation
If you find this code, or the findings in the paper relevant for your work, please considering citing our manuscript:

_Cargnelli, CB, Nielsen, JV and Madsen JGS (2026): **Benchmarking computational decontamination of ambient RNA.** bioRxiv._
